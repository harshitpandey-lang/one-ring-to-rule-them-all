# NOV 5: Designed the Repo and selected the components

Spent the day figuring out the features I will need to make this ring. I figured out that I will need to make a ring that can soemhow counts the number of times I tap or rotate it-- the reason for this device is that in Tradational practice of meditation people chant holy names of god using a "mala" but in this world of tech we can use a ring that can help us meditate and also looks cool. 
### Purpose:-

>1. It is going to be used to store the number of rotation the ring will made and show it on the screen and it will be used to chant the holy names.

### Features:-

>1. It will count the number of rotations
>2. it has a display to show numbers
>3. it has a reset buttons
>4. it looks cool as it is made up of PCB
>5. it is made up two circular rings one of them will be static and the outer one will move that will have all the components
>6. the lower ring has a magnet that when will be crossed through the hall effect sensor will count as one rotation.

### Components used:-

>1. "DRV5032" - hall effect sensor
>2. "LR44 1.5V Micro Alkaline" - Coin Battery
>3. "ATTINY402-SSN-MICROCHIP-8 Bit MCU" - Microcontroller
>4. "0.42-inch I²C OLED module" - Display
>5. "Miniature tactile switch" - Switch
>6. Miniature permanent magnet
>7. Flexible PCB
>8. Miniature permanent magent
